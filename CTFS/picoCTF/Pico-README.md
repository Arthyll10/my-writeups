# 🚩 picoCTF Walkthroughs & Notes

Welcome to my **picoCTF** writeup collection! picoCTF (via CyLab Academy) was the very first platform I used to jump into the world of Capture The Flag (CTF) competitions. 

Learning cybersecurity concepts here has been an awesome and fun experience. The hands-on, gamified challenges make it easy to grasp complex topics—from terminal navigation to web security and reverse engineering—one step at a time.
